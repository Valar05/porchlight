## Commission

Porchlight is an accessible, community-reviewed map of the internet kept current by deterministic local workers. The map is the product; the worker is a replaceable discovery and verification instrument.

## Current capability

- Public source repository: delivered.
- Deterministic Node worker and chat-shaped CLI: implemented and tested.
- Gesture-paired MV3 extension with pinned bootstrap identity: implemented and tested.
- Semantic DOM inventory and deterministic actions: implemented and tested.
- One-use approval for submit/send/file: implemented and tested.
- Privacy-safe receipts, metrics, discovery graduation, site-pack generation, accessible HTML/JSON map, query CLI, and freshness checks: implemented and tested.
- Public site-pack contribution through GitHub PRs: implemented; requires each worker's configured git/GitHub authority.
- Packaged extension/store listing: not delivered.
- Hosted public map: deployed as a read-only GitHub Pages projection at https://valar05.github.io/porchlight/; each relevant main change and nightly schedule rebuilds it from reviewed site packs.
- Any particular user's browser installation or site pairing: not implied.
- Remote institutional receipt or indexing: never inferred from a page action.

## Sealed boundaries

Public contributions exclude URL paths/query strings, accounts, typed values, raw DOM, screenshots, cookies, credentials, case/claim numbers, and user identifiers. Routes graduate after three verified successes across two document instances. Motivated Mode is central and permanent but cannot expand authority.

## Active gate

Grow the hosted map through privacy-safe site-pack PRs and add a reproducible signed/package release lane without weakening local-only operation or receipt truth.
